# Day 1 问答笔记（今天搞懂的知识点）

## 一、终端

### 快捷键
- `Ctrl + \`` ：打开 / 关闭终端
- `Ctrl + Shift + \`` ：新建一个终端标签页
- `Ctrl + C` ：停止正在运行的程序 / 取消当前命令
- `Ctrl + K` 后按 `V` ：Markdown 左右分栏预览
- `Ctrl + Shift + V` ：切换 Markdown 预览（开关式）

### 我踩过的坑
- `echo"文字"` ❌ 报错：命令和引号之间**少了空格**
- `echo "文字"` ✅ 正确：**命令和参数之间必须有空格隔开**
#### echo 是什么
echo=让电脑说话
### 看懂报错（口诀）
- `CommandNotFoundException` = 找不到命令
- 排查三步：① 拼写对不对 ② 空格有没有 ③ 程序装了没
- `所在位置 行:1 字符:1` = 告诉你错在第几行第几个字符

## 二、Markdown（.md 文件）

### .md 是什么
- 带格式的纯文本记事本
- 程序员用来写笔记、文档、README
- 对比：txt 没格式，docx 太重；md 轻量又漂亮

### 标题（共 6 级，# 越多越小）
- `#` 一级标题（一篇只用一个）
- `##` 二级标题（大板块）
- `###` 三级标题（知识点）
- `####` 四级标题（更细分）
- 注意：# 和文字之间要加**空格**

### 列表
- `- 内容` ：无序列表（自动带圆点），减号后要加空格
- `1. 内容` ：有序列表（自动编号）
- `- [ ]` ：待办事项（空方框）
- `- [x]` ：已完成事项（打勾）

### 文字格式
- `**文字**` ：加粗
- `` `代码` `` ：代码样式
