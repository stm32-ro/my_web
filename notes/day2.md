# Day 2 问答笔记（Node.js 与开发者工具）

## 一、Node.js 安装

### 版本选择（重要概念）
- **LTS**（Long Term Support）= 长期支持版，稳定 → 装这个
- **Alpha / Latest** = 尝鲜测试版，不稳定 → 不装
- 我装的版本：**v26.13.0（LTS）**

### 安装包怎么选（官网那一大堆链接）
- Windows 64 位**安装程序 (.msi)** → 就下这个，双击自动配置
- 二进制 (.exe) = 免安装但要手动配环境 → 不用
- macOS / Linux / 源代码 → 别人的系统用的 → 不管

### 安装要点
- Custom Setup 页四项**全保持默认**（尤其 Add to PATH 不能取消）
- Tools for Native Modules 页**不勾选**直接跳过
- 装完必须**重启 VS Code**，终端才认识新命令

## 二、今天踩的坑与修复

### 坑 1：中文引号导致卡住
- `echo "文字` 用了中文引号 → PowerShell 显示 `>>` 一直等待
- 解决：`Ctrl + C` 取消，切英文输入法重打
- 教训：**代码和命令里的引号、逗号、分号一律用英文标点**

### 坑 2：npm 报"禁止运行脚本"
- 原因：PowerShell 默认安全策略拦截脚本
- 解决（一行命令）：
  - `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`
  - 弹确认输 `Y` 回车
- 记忆：RemoteSigned = 允许本地脚本，网上脚本要签名（安全又方便）

## 三、命令行新知识

### node 交互模式
- 终端输入 `node` 回车 → 提示符变成 `>` → 直接写 JS 代码
- 试过：`1+1`、`"你好"+"世界"`、`3 > 5`、`1234*5678`
- 退出：按两次 `Ctrl + C`
- 记忆：`node` 单独 = JS 计算器；`node 文件.js` = 运行文件（Day 11 用）

### 命令行"没消息 = 成功"
- `Set-ExecutionPolicy` 没任何输出直接回提示符 = 成功了
- 命令行只有出错才会大声嚷嚷

### 命令的通用结构
- 命令 + 空格 + 参数，例：`echo "内容"`、`node -v`、`git commit -m "说明"`

## 四、F12 开发者工具（DevTools）

### 打开方式
- 按 `F12`，或在网页上**右键 → 检查**（最常用，自动定位）

### 各面板作用
- **元素（Elements）**：看/改网页结构 ← 今天玩的就是它
- 控制台（Console）：直接执行 JS（Day 11 后常用）
- 网络（Network）：看网页请求（Day 14 调 API 用）
- 应用程序（Application）：看 Cookie、本地存储（Day 25 登录用）

### 修改网页文字四步
1. 网页上对文字**右键 → 检查**（代码自动定位并高亮）
2. 找不到就 `Ctrl + F` 在面板里搜索那个词
3. **双击** `>` 和 `<` 之间的文字 → 改成想要的 → 回车
4. 双击没反应 → 右键 →「以 HTML 格式修改」，改完点外面生效

### 重要理解
- DevTools 改的只是**本地显示**，刷新就还原
- 真正的代码在**服务器**上——所以前端要配合后端才有真数据
